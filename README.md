# Mini Library Management System

Mini library management system developed in python to perform add, view and check the availability of books, borrow and return of books from the library through command line.

## Features

• Add a new book

• View the books in the library

• Store ISBN number, book name and author name

• Avoids duplicate ISBN number

• Availability check of the book

• Borrow a book

• Return a book

• View the status of the book whether it is available or borrowed

• Interactive menu driven interface

## Technologies

• Python

## Approach

The mini library management system stores the information of books in python list. Every book is stored as a dictionary with keys as ISBN number, book name, author name and availability of the book. The application provides an interactive command line menu driven interface to perform the tasks such as adding a book to the library, view the books, borrow a book, return a book and exit the application.
